Default Configuration

⚙️ Custom Configuration

Custom Configuration

const fretboard = new Fretboard({
  fretCount: 12,
  stringCount: 6,
  orientation: 'horizontal',
  stringSpacing: 30,
  fretSpacing: 60,
  stringThickness: 0.5,
  fretThickness: 3
});

🎯 Position Queries & Markers

Click on the fretboard to add a marker. The position will be logged to console.

Interactive Fretboard (click to add markers)

// Get positions
fretboard.getFretPosition(5);    // { x: 120, y: 0 }
fretboard.getStringPosition(2);   // { x: 0, y: 40 }
fretboard.getMarkerPosition(5, 2); // { x: 120, y: 40 }

// Add markers
fretboard.addMarker(5, 2, { color: 'red', size: 8 });
